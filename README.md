# 今日油价

一个 uTools 插件，用于查询全国各省市最新成品油价格。数据来源中国石化公开接口，无需登录。

针对原站的两个痛点做了改进：**进入即自动定位所在省份**，**手动选择的省市与价区会被长期记住**，下次打开直接显示。

## 功能

- **今日油价** — 当前各标号挂牌价，涨跌以红色（上调）/ 蓝色（下调）区分；多价区省份（如四川、云南、陕西）可切换价区
- **历史油价** — 近一年每次调价的完整记录，表格按该省份实际在售标号动态生成
- **调价日历** — 当月及后续两个月的调价日日历
- **覆盖标号** — 89/92/95/98 号汽油、E92/E95/E98、爱跑系列、0 号及各负号柴油、LNG / L-CNG / CNG（天然气按元/千克计价）

在 uTools 中输入「油价」「今日油价」「加油」任一关键词即可唤起。

## 安装

1. 构建产物：`npm install && npm run build`
2. 打开 uTools 开发者工具，将插件项目目录指向本仓库的 `dist/` 目录

`dist/` 是自包含的单文件产物，无需启动本地服务即可加载。

## AI Agent 调用（MCP）

插件注册了 3 个工具，可经 uTools 的 MCP 服务供第三方 AI Agent 调用：

| 工具 | 参数 | 说明 |
| --- | --- | --- |
| `oil_price_get` | `province`（可选） | 查询当前各标号油价与涨跌幅 |
| `oil_price_history` | `province`（可选）、`limit`（可选，默认 12，上限 24） | 近一年调价记录 |
| `oil_price_provinces` | 无 | 列出支持的省市 |

`province` 接受省名、全称、英文别名或编号，例如 `湖北`、`广西壮族自治区`、`Hubei`、`42`。不传时按「用户上次选择 → IP 定位」的顺序降级。

在 Agent 的 MCP 配置中加入：

```json
{
  "mcpServers": {
    "utools": {
      "type": "http",
      "url": "http://127.0.0.1:3501/mcp",
      "headers": { "x-mcp-key": "<从 uTools 设置 → MCP 服务中复制>" }
    }
  }
}
```

需先在 uTools 设置中开启 MCP 服务。`x-mcp-key` 是敏感凭据，请勿提交到版本库。

## 开发

```bash
npm install
npm run dev     # 本地热更新，服务监听 127.0.0.1:5173（调试时 uTools 指向 public/）
npm run build   # 生成 dist/（测试发布产物时 uTools 指向 dist/）
```

构建会内联 CSS/JS 为单个 `index.html`，并剥离 `plugin.json` 中的 `development` 字段，确保产物可离线加载。

技术栈：Vue 3 + Vite。接口无 CORS 响应头，所有网络请求在 `public/preload.js` 的 Node 环境发起。省市与油品定义集中在 `public/shared/oil-data.json`，由 preload 与渲染层共用。

贡献前请阅读 [AGENTS.md](./AGENTS.md)。

## 说明

- 位置识别基于网络 IP，开启代理或 VPN 时可能定位到出口节点所在城市，手动选择一次即可覆盖
- 少数省市当期价格尚未发布时，会显示最近一次已公布的价格并标注生效日期
- 价格仅供参考，实际以加油站挂牌价为准
- 数据来自中国石化公开接口，如上游调整接口，插件会显示错误提示而非崩溃
